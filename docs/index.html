Architecture

The project provisions one VPC 10.0.0.0/24 with a public subnet for the web server and a private subnet for the Ansible controller and monitoring server. Access is SSM-first, with no SSH ingress required for private instances.

  • Web server: 10.0.0.5, public Elastic IP, Docker app on port 80, node_exporter on port 9100.
  • Ansible controller: 10.0.0.135, private subnet, runs configuration through AWS SSM.
  • Monitoring server: 10.0.0.136, private subnet, Prometheus and Grafana as containers.

Delivery Flow

  1. Run scripts/preflight-check.sh to verify GitHub, AWS CLI, AWS identity, and SSM readiness.
  2. Bootstrap Terraform state in terraform/bootstrap.
  3. Apply production infrastructure in terraform/envs/prod.
  4. Build and push the app image to ECR through GitHub Actions.
  5. Deploy from the Ansible controller to the web and monitoring instances.
  6. Configure Cloudflare DNS and Tunnel for the public application and private Grafana access.

For a full A-Z rebuild guide with 5W1H notes, open docs/walkthrough/README.md. For the deeper build-from-zero version with code logic, fundamentals, and assessment checkpoints, open docs/walkthrough/detailed-build.md. For the two-phase learning path, open docs/walkthrough/phased/README.md.

Cloudflare Notes

Create an A record for web.hadiyahyalab.com pointing to the Terraform output web_public_ip. Create a Cloudflare Tunnel route for monitoring.hadiyahyalab.com to reach Grafana on the private monitoring server at http://10.0.0.136:3000.
